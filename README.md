Ember Ridge Run is an original pseudo-3D flight game: take off from a valley runway, thread glowing rings over ridges, lakes and pine forest across three missions, manage throttle, fuel and the wind, then bring the plane home for a gear-down landing. Keyboard and mouse, offline, in any desktop browser.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. Arrows / WASD fly, Shift / Ctrl work the throttle, G lowers the gear, P pauses, R restarts.
